## 🚀 Featured Projects

### 🧠 Employee Sentiment Analysis
> Analyzes the Enron email dataset to understand employee mood, identify flight risks, and predict future sentiment using NLP and ML.

- Answers questions like overall sentiment distribution and company-wide trends over time
- Flags employees sending unusually negative messages (flight risk detection)
- Sentiment prediction via Linear Regression (R² ≈ 0.30) on rolling averages
- Chose **TextBlob** over VADER for more balanced results on professional language

**Stack:** `Python` `TextBlob` `scikit-learn` `Pandas` `Matplotlib` `Jupyter Notebook`

[![GitHub](https://img.shields.io/badge/View_Repo-161b22?style=flat-square&logo=github&logoColor=white)](https://github.com/Dharshan-ui/Employee-Sentiment-Analysis)

### 🎵 Musify V2
> A modern music streaming web app — browse albums, stream songs, and manage your profile with Firebase auth and Cloudinary media uploads.

- Firebase Auth + Firestore for real-time user and library management
- Admin dashboard for song/album uploads via Cloudinary
- Mini player with full playback controls and smooth Framer Motion animations
- Role-based access: regular users vs. admins

**Stack:** `React 19` `Vite 6` `Tailwind CSS v4` `Firebase` `Cloudinary` `Framer Motion` `React Router v7`

[![GitHub](https://img.shields.io/badge/View_Repo-161b22?style=flat-square&logo=github&logoColor=white)](https://github.com/Dharshan-ui/Musify-V2)
